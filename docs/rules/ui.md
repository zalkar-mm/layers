# UI

Смежные темы: [code-style.md](code-style.md), [testing.md](testing.md).

## 1. Стили

- **styled-components 6.** UI-библиотеки компонентов (MUI, Ant и т.п.) запрещены.
- **Только токены темы** (`shared/ui/theme`): цвета, отступы, радиусы, размеры шрифтов. Значение вне шкалы — вынести в константу с говорящим именем.
- Тема типизирована через `DefaultTheme` — `theme.colors.x` проверяется компилятором.
- **Transient-пропсы** для стилей: `$active`, `$tone`. Без `$` проп улетает в DOM.
- `style={{}}` — только для рантайм-значений (например, ширина из вычисления). Для opacity на карте — MapLibre, не CSS.
- Styled-компоненты объявляются **под** компонентом в том же файле, если используются только в нём. Второе использование → `shared/ui`.
- Mobile-first: базовые стили для 360 px, `@media (min-width: ${theme.breakpoints.desktop})` для десктопа. Тач-цели от 44 px.

## 2. Компоненты

- Перед созданием компонента проверь `shared/ui` (правило одного анализа).
- Компонент строки получает только `id`, остальное берёт хуком ([code-style §4](code-style.md#4-react)).
- Композиция через `children` предпочтительнее пропсов-слотов.
- Нативные элементы с правильной семантикой: `<button>`, `<input type="range">`, `<label>`. `div` с `onClick` запрещён.

## 3. Состояния данных

Компонент с асинхронными данными явно показывает каждое состояние. Для слоя — все ветки `LoadState` из ТЗ §4.2, тексты бейджей — ТЗ §7.2. Ошибка никогда не выглядит как «пусто», а загрузка поверх кэша — как «пусто → данные».

## 4. Тексты

- Весь интерфейс на русском. Тексты — дословно из ТЗ, если там заданы.
- Числа и время форматируются через `Intl` с локалью `ru-RU`.
- Ошибки для пользователя — человеческим языком, без стектрейсов и кодов.

## 5. Доступность

Требования — ТЗ §11.2. Коротко:

- Всё управляется с клавиатуры, видимый `:focus-visible`.
- Тумблер — `role="switch"` + `aria-checked`. Слайдер — нативный `range` с `aria-valuetext`.
- Смена статуса слоя — `aria-live="polite"`.
- У каждого контрола доступное имя (`<label>` или `aria-label`) — по нему же пишутся тесты ([testing §4](testing.md#4-селекторы)).

## Что запрещено

- ❌ UI-библиотеки компонентов — ревью, зависимость не согласуется.
- ❌ Цвета, отступы, радиусы мимо темы — ревью.
- ❌ Стилевые пропсы без `$` — ревью (styled-components предупреждает в консоли).
- ❌ Кликабельный `div`, контрол без доступного имени — тесты по ролям, ревью.
- ❌ Английский текст в интерфейсе — ревью.
