# Ревью

Ревью diff этапа проводит отдельный субагент со свежим контекстом (`.claude/agents/frontend-developer.md` §5, шаг 7). Он ссылается на правила, а не пересказывает их.

## 1. Формат находки

```
src/features/layer-control/model/enable.ts:42
ПРОБЛЕМА: результат пишется в стор без проверки requestId (state-and-async §4)
КАК: сравнить byId[id].load.requestId с токеном запроса перед dispatch
```

Каждая находка — путь:строка, ссылка на правило или пункт ТЗ, конкретное исправление.

## 2. Приоритеты

| Уровень | Что | Действие |
|---|---|---|
| **P0** | Критерий приёмки ТЗ не выполнен или не покрыт тестом; гонка; утечка; нарушение запрета §13 ТЗ; `yarn check` красный | Не коммитим, пока не исправлено |
| **P1** | Нарушение правил `docs/rules`; лишний рендер; логика в `ui/`; неточный текст интерфейса | Исправляем в этом же этапе |
| **P2** | Нейминг, читаемость, мелкие улучшения | Исправляем, если дёшево; иначе строка в «Открытые вопросы» отчёта этапа |

## 3. Чек-лист

1. **ТЗ:** каждый критерий этапа выполнен и покрыт тестом — с номерами (§x.y, R*, строка §8, E*).
2. **Архитектура:** направление импортов, public API, сегменты ([architecture](architecture.md)).
3. **Запреты §13 ТЗ:** `any`, `as`, `!`, `@ts-ignore`, async-dispatch, загрузка в `useEffect`, `dispatch` в пропсах, логика в UI.
4. **Рендеры:** новые объекты и функции в пропсах `memo`-компонентов; мемоизация без теста.
5. **Утечки:** подписки, таймеры, `AbortController`, экземпляр карты освобождаются.
6. **Честность:** цифры в README и `AI_LOG.md` подтверждены запуском.

## 4. Что НЕ флагаем

- Форматирование и порядок импортов — это делает Prettier и `simple-import-sort`.
- То, что уже ловит ESLint, TypeScript или steiger, если `yarn check` зелёный.
- Вкусовой выбор без правила («я бы назвал иначе»), если имя соответствует [code-style §1](code-style.md#1-нейминг).
- Отсутствие абстракции «на вырост».
- Код вне diff этапа — отдельной строкой в «Открытые вопросы», не находкой.

## 5. После ревью

Каждую находку перепроверить самому. Подтверждённые — исправить. Отклонённые — перечислить в отчёте этапа с причиной.
