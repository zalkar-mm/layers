# ADR 007: React Compiler не используется

**Статус:** Принято
**Дата:** 2026-09-25
**Этап ТЗ:** 0

## Контекст

ТЗ §8 требует доказать бюджет рендеров: при движении слайдера перерисовывается одна строка. Ревьюер проверяет ручной контроль рендеров (ТЗ §0, пункт 3). React Compiler автоматически мемоизирует компоненты и значения.

## Варианты

| Вариант | Плюсы | Минусы |
|---|---|---|
| Включить React Compiler | Меньше ручных `memo`/`useCallback` | Бюджет рендеров держится на компиляторе, а не на архитектуре; проверяющий не видит, где и почему сделана мемоизация; ещё одна зависимость и Babel-шаг в сборке |
| Не включать | Каждая мемоизация видна в коде и обоснована тестом | Мемоизацию расставляем руками |

## Решение

Не включаем. Бюджет рендеров обеспечивается архитектурой: строка получает только `id`, подписка точечная: селектор отдаёт маленький вид строки, перерисовка — только при его изменении ([ADR 009](009-standard-vedro-api.md)), structural sharing в сторе. Ручная мемоизация — только там, где её требует §8, и каждый случай подтверждён тестом ([code-style §4](../rules/code-style.md#4-react)).

## Последствия

- `babel-plugin-react-compiler` не устанавливается.
- Из `eslint-plugin-react-hooks` включены только `rules-of-hooks` и `exhaustive-deps`: правила пресета `recommended` для компилятора не нужны.
- Тесты бюджета рендеров (этап 6) проверяют архитектуру, а не работу компилятора.
